# Changelog

## 1.0.0

First release, for Minecraft 1.21.1 / NeoForge 21.1.

- Particle scan around the crosshair, with results listed by particle type ID (or class name for untyped particles)
- Hide particles everywhere, or only inside named, movable, resizable zones
- Hide breaking, mining and block-dust particles by block ID, mod (`namespace:*`), or tag (`#tag`)
- One menu (`/particles`) listing everything hidden and where
- Live zone outlines while editing
